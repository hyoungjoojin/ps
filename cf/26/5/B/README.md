# Roadside Trees (Simplified Edition)

> ID: CF 265B \
> Level: 1000

## Description

Liss is on the root of the tree with the number 1. In one second Liss can
perform one of the following actions:

- Walk up or down one unit on a tree.
- Eat a nut on the top of the current tree.
- Jump to the next tree. In this action the height of Liss doesn't change.

Compute the minimal time (in seconds) required to eat all nuts.
