# Find the Different Ones!

> ID: CF 1927D \
> Level: 1300

## Description

Given an array of integers, for a given query of $(l, r)$, find any pair of
indices $i, j$ such that $l \leq i < j \leq r$ and $a_i \neq a_j$.
