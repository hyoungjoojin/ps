# Divisible Pairs

> ID: CF 1931D \
> Level: 1300

## Description

Given an array of integers and two values $x$ and $y$, find the number of pairs
of indices $(i, j)$ such that $i < j$ and $(a_i + a_j) \mod x = 0$ and
$(a_i - a_j) \mod y = 0$.
