# Frog 1

> ID: AC DP-A

## Description

Given an array of integers, the cost of moving from position $i$ to $j$ is
$|h_i - h_j|$. If we can only move from position $i$ to $i + 1$ or $i + 2$, find
the minimum cost to move from the start to the end.
