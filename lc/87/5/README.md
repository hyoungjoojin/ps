# Koko Eating Bananas

> ID: LC 875 \
> Level: Medium

## Description

Given $n$ piles of bananas, find the minimum integer eating speed $k$ such that
eating at most $k$ bananas per hour from a single chosen pile each hour, all
piles can be finished within $h$ hours.
