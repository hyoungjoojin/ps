# Collecting Numbers

> ID: CSES 2216

## Description

Given a permutation of numbers from 1 to $n$, count the minimum number of rounds
required to collect all numbers in increasing order. In one round, you can
collect numbers from left to right, but you can only collect a number if it is
greater than the last collected number.
