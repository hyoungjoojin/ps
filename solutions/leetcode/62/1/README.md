# Task Scheduler

> ID: LC 621 \
> Level: Medium

## Description

Given an array of tasks with a label of capital letters A to Z, each task takes
one unit of time and requires $n$ units of time to wait before the same task can
be executed again. Return the least number of units of times that the CPU will
take to finish all the given tasks.
