# Integers With Multiple Sum of Two Cubes

> ID: LEETCODE 3890 \
> Level: Medium

## Description

Given an integer $n$, find the number of integers in the range $[1, n]$ that can
be expressed as a sum of cubes of two positive integers in at least two distinct
ways.
