> ID: BOJ 2243 \

## Description

We are given an empty bag of integers. We perform the following operations on
the set.

- Insert $N$ instances of value $x$ into the bag.
- Remove $N$ instances of value $x$ from the bag.
- Find and remove the $k$-th smallest value in the bag.
