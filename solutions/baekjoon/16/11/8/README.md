# 달빛 여우

> ID: BOJ 16118 \
> Level: Gold 1

## Description

Given a weighted graph, a fox and a wolf walks on the graph. The fox walks at a
constant speed, while the wolf alternates between double speed and half speed.
The task is to determine how many vertices the fox can reach faster than the
wolf.
