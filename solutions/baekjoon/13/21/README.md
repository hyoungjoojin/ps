## Description

Given an array of integers, apply the following operations.

- Add or subtract a value from a position in the array.
- Get the index $i$ such that $\sum_{j=1}^{i} a_j \ge k$ and
  $\sum_{j=1}^{i-1} a_j \lt k$.
