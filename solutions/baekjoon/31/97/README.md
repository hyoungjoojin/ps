# 백조의 호수

> ID: BOJ 3197 \
> Level: Platinum 5

## Description

Given a grid where cells can either be water or land, for each time iteration
the water expands to adjacent land cells. Find how long it takes for two swans
located on the grid can meet each other, where they can only move through water
cells.
